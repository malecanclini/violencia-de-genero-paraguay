# Dónde Denunciar: Mapa de Recursos para la Atención y Denuncia de Violencia de Género en Paraguay

## Descripción

**Dónde Denunciar** es una aplicación web interactiva que centraliza información sobre recursos de atención, protección y denuncia para mujeres en situación de violencia de género en Paraguay.

El proyecto busca facilitar el acceso rápido a servicios esenciales mediante una interfaz intuitiva que integra cartografía digital, directorios de instituciones, teléfonos de emergencia e información práctica sobre los pasos para realizar una denuncia.

La herramienta está diseñada para servir como punto de acceso a información crítica, permitiendo identificar centros de atención, servicios jurídicos, apoyo psicológico, albergues y organismos de respuesta ante situaciones de violencia.

---

## Objetivos

- Facilitar el acceso a información confiable sobre servicios de atención a mujeres.
- Visualizar geográficamente recursos de apoyo y denuncia.
- Mejorar la accesibilidad a teléfonos y canales de emergencia.
- Contribuir a la difusión de herramientas de prevención y protección frente a la violencia de género.
- Explorar el uso de tecnologías geoespaciales para abordar problemáticas sociales.

---

## Funcionalidades

### Mapa interactivo

- Visualización geográfica de centros de atención y denuncia.
- Localización de recursos en diferentes departamentos del país.
- Marcadores diferenciados por categoría de servicio.

### Búsqueda y filtrado

- Búsqueda por nombre de institución, dirección o ciudad.
- Filtros por tipo de servicio: 
    - Emergencia
    - Asesoramiento legal
    - Apoyo psicológico
    - Albergue o refugio
    - Atención policial

### Información detallada

Cada punto incluye:

- Nombre de la institución.
- Dirección.
- Teléfono de contacto.
- Horarios de atención.
- Servicios ofrecidos.
- Enlace para visualización de ubicación.

### Panel de emergencia

Acceso rápido a números de atención como:

- SOS Mujer (137)
- Policía Nacional (911)
- Defensoría Pública (133)
- Otros servicios especializados.

### Guía para realizar denuncias

Sección informativa con orientación básica sobre los pasos recomendados para efectuar una denuncia y acceder a mecanismos de protección.

## Estructura de datos

Los recursos georreferenciados incluyen información como:

- Categoría de servicio.
- Coordenadas geográficas.
- Datos de contacto.
- Horarios de atención.
- Servicios disponibles.

Esta estructura permite la futura integración con bases de datos externas, APIs o servicios geoespaciales más avanzados.

---

## Impacto esperado

La violencia de género representa una problemática que requiere respuestas accesibles y oportunas. Este proyecto explora cómo las tecnologías geoespaciales pueden contribuir a mejorar el acceso a información crítica para mujeres que necesitan orientación, asistencia o protección.

La herramienta busca demostrar el potencial de los sistemas de información geográfica y la cartografía digital en iniciativas de impacto social.
